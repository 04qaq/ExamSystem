# 解决方案文档

基于代码评审报告，按优先级排列的解决方案。优先修复影响用户体验的问题。

---

## 一、直接影响用户体验的 Bug 修复

### 1.1 PaperList 模态框遮罩层不工作

**问题**: `PaperList.vue:215` 的 CSS 选择器缺少 `.` 前缀，写成了 `modal-overlay` 而非 `.modal-overlay`，模态框无遮罩层。

**修复**: 补上 `.` 前缀。

### 1.2 Login 页面硬编码默认凭据

**问题**: `Login.vue:53` 表单默认填入 `admin/admin123`。

**修复**: 使用空字符串初始化表单，避免生产环境安全风险。

### 1.3 PaperQuestions 分数修改无效果

**问题**: `PaperQuestions.vue:224-227` 的 `updateScore` 函数体为空，修改分数后不保存。

**修复**: 实现 `updateScore` 调用 `addQuestions` API 保存分数变更。

### 1.4 列表页缺少错误状态

**问题**: `OperationLogs.vue`, `QuestionList.vue`, `PaperList.vue`, `UserManagement.vue` 等列表视图只处理"加载中"和"空数据"两个状态。API 失败时用户看到"暂无数据"而非错误提示。

**修复**: 增加 `error` 状态变量，在 API 失败时显示错误信息。

### 1.5 StudentDashboard 进行中数量永远为 0

**问题**: `StudentDashboard.vue:48-51` 的 `inProgressCount` 返回硬编码 `0`。

**修复**: 根据 `papers` 列表中有 `my_record_id` 的条目计算进行中的考试数（与已交卷的区别在于状态码）。

### 1.6 ExamTaking 空题目列表保护

**问题**: `ExamTaking.vue:183` 使用 `{} as ExamQuestion` 作为空列表时的后备值，访问属性返回 `undefined`。

**修复**: 改用带默认值的后备对象，并在模板中用 `v-if` 保护。

## 二、代码一致性改进

### 2.1 提取共享标签函数

**问题**: `typeLabel`、`statusLabel`、`difficultyLabel` 在 8+ 个 Vue 文件中重复定义，且部分用短格式部分用长格式。

**修复**: 创建 `src/utils/labels.ts`，统一导出所有标签函数。

### 2.2 移除前端的冗余本地接口定义

**问题**: `OperationLogs.vue` 和 `UserManagement.vue` 在本地重新定义了 API 层已有的接口。

**修复**: 直接导入 API 层定义的接口类型。

### 2.3 修复前端 catch 块中的 `any` 类型

**问题**: 所有 catch 块使用 `(err: any)`，违反 TypeScript 最佳实践。

**修复**: 改为 `(err: unknown)`。
