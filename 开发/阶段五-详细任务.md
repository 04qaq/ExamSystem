# 阶段五：成绩与批阅模块 - 详细任务

## 目标
教师批阅主观题、查看成绩统计；学生查看成绩详情（已在阶段四完成）。

## 任务清单

## 第一部分：服务端（Server）

### 任务 5.1：教师 DTO 定义

**文件**: `internal/dto/grade.go`

| 结构体 | 说明 |
|--------|------|
| `PendingGradeRecord` | 待批阅记录项：record_id, 学生姓名, 试卷名称, 提交时间, 主观题数量, 当前得分 |
| `PendingGradeListResponse` | 分页待批阅列表 |
| `GradeDetailItem` | 批阅题目项：detail_id, question_id, 题干, 学生答案, 标准答案, 满分, 当前得分 |
| `PendingGradeDetailResponse` | 某份记录的批阅详情：record_id, paper_title, student_name, 题目列表 |
| `GradeRequest` | 批阅请求：detail_id, score_gained, comment |
| `GradeBatchRequest` | 批量批阅请求：grades: [{detail_id, score_gained, comment}] |
| `PaperStatistics` | 试卷统计：paper_id, paper_title, total_students, submitted_count, avg_score, max_score, min_score, pass_count, fail_count, pass_rate |
| `QuestionStatItem` | 题目统计：question_id, content, type, total_count, correct_count, correct_rate, avg_score |
| `StatisticsResponse` | 完整统计：paper_stat 基本信息 + question_stats 每题统计 + score_distribution 分数段分布 |

### 任务 5.2：批阅 Repository

**文件**: `internal/repository/grade_repo.go`

- `GetRecordsByPaperID(paperID uint64) ([]model.ExamRecord, error)` — 获取某试卷所有记录
- `GetPendingRecords(teacherID uint64, page, pageSize int) ([]model.ExamRecord, int64, error)` — 获取该教师创建试卷的待批阅记录（status=2 已提交待批阅；或 status=3 但主观题仍有未批阅的）
- `GetPendingSubjectiveDetails(recordID uint64) ([]model.AnswerDetail, error)` — 获取某记录中主观题（type=4/5）且 is_correct IS NULL 的题目
- `GetAllDetailsByRecord(recordID uint64) ([]model.AnswerDetail, error)` — 获取某记录全部答题详情
- `BatchUpdateScores(details []*model.AnswerDetail) error` — 批量更新得分

### 任务 5.3：批阅 Service

**文件**: `internal/service/grade_service.go`

**1. GetPendingList** — 待批阅列表
- 查询教师创建的所有试卷中，学生已提交的考试记录
- page+pageSize 分页，返回记录摘要（学生名、试卷名、提交时间、主观题数）

**2. GetGradeDetail** — 批阅详情
- 返回某考试记录的全部答题项
- 客观题显示已判结果，主观题显示待批阅状态

**3. GradeSubmit** — 提交批阅
- 接收批量批阅请求 [{detail_id, score_gained, comment}]
- 更新 answer_details 表
- 检查该记录是否所有主观题已批阅完毕：
  - 是 → 重算总分（客观题得分 + 主观题得分），更新 exam_records.status=3（已批阅）
  - 否 → 只更新得分，状态保持不变

**4. GetPaperStatistics** — 试卷统计
- 查询某试卷的所有已提交记录
- 计算参考人数、平均分、最高分、最低分、及格人数/不及格人数、及格率
- 每题正确率统计
- 分数段分布：[0-30), [30-60), [60-70), [70-80), [80-90), [90-100]

### 任务 5.4：成绩导出（Excel）

- 使用 `excelize` 库生成 Excel 文件
- 导出内容：学生姓名、得分、每题得分明细、提交时间
- 返回文件下载

### 任务 5.5：批阅 Controller

**文件**: `internal/controller/grade_controller.go`

```go
GET    /api/teacher/exam/pending          — 待批阅列表
GET    /api/teacher/exam/records/:id/grade — 批阅详情（含所有题目）
POST   /api/teacher/exam/records/:id/grade — 提交批阅打分
GET    /api/teacher/statistics/paper/:id   — 试卷统计
GET    /api/teacher/statistics/paper/:id/export — 导出 Excel
```

### 任务 5.6：注册路由

**文件**: `internal/router/router.go`

在 teacher 路由组中添加：
```go
teacher.GET("/exam/pending", gradeCtrl.GetPendingList)
teacher.GET("/exam/records/:id/grade", gradeCtrl.GetGradeDetail)
teacher.POST("/exam/records/:id/grade", gradeCtrl.GradeSubmit)
teacher.GET("/statistics/paper/:id", gradeCtrl.GetPaperStatistics)
teacher.GET("/statistics/paper/:id/export", gradeCtrl.ExportExcel)
```

## 测试用例

```bash
# 教师查看待批阅列表
curl http://localhost:8080/api/teacher/exam/pending -H "Authorization: Bearer <teacher_token>"

# 查看批阅详情
curl http://localhost:8080/api/teacher/exam/records/1/grade -H "Authorization: Bearer <teacher_token>"

# 提交批阅
curl -X POST http://localhost:8080/api/teacher/exam/records/1/grade \
  -H "Authorization: Bearer <teacher_token>" \
  -H "Content-Type: application/json" \
  -d '{"grades":[{"detail_id":1,"score_gained":5,"comment":"正确"}]}'

# 试卷统计
curl http://localhost:8080/api/teacher/statistics/paper/1 -H "Authorization: Bearer <teacher_token>"

# 导出 Excel
curl http://localhost:8080/api/teacher/statistics/paper/1/export -H "Authorization: Bearer <teacher_token>" --output scores.xlsx
```
