# 阶段三：试卷管理模块 - 详细任务

## 目标
服务端实现试卷 CRUD + 手动/随机组卷 + 发布/复制；客户端实现教师试卷管理界面（列表、创建向导、预览）。

## 依赖
- 阶段二已完成（题库 CRUD + 批量导入）

## 任务清单

## 第一部分：服务端（Server）

### 任务 3.1：试卷 DTO 定义

**文件**: `internal/dto/paper.go`

| 结构体 | 说明 |
|--------|------|
| `CreatePaperRequest` | 创建试卷：title, description, duration, total_score, start_time, end_time |
| `UpdatePaperRequest` | 修改基本信息（同 CreatePaperRequest） |
| `PaperQuery` | 分页查询：page, page_size, keyword, status（form 标签） |
| `PaperResponse` | 返回给前端的试卷数据 |
| `PaperListResponse` | Total + Items |
| `AddQuestionsRequest` | 手动选题：questions [{question_id, score}] |
| `RandomSelectRule` | 随机规则：type, count, total_score |
| `RandomSelectRequest` | 随机组卷：rules []RandomSelectRule |
| `PaperQuestionItem` | 试卷中的题目关联信息（含 question 部分字段） |
| `PaperPreviewResponse` | 试卷预览：paper + questions |

### 任务 3.2：试卷 Repository

**文件**: `internal/repository/paper_repo.go`

- Create / Update / Delete / FindByID / List（分页 + keyword + status + creatorID）

**文件**: `internal/repository/paper_question_repo.go`

- BatchCreate / GetQuestions（关联 Question 表）/ ClearByPaperID / RemoveQuestions / GetQuestionIDs

### 任务 3.3：试卷 Service

**文件**: `internal/service/paper_service.go`

- Create: 创建试卷基本信息
- Update: 修改（仅草稿）
- Delete: 删除（仅草稿）
- List: 分页查询（按创建者隔离）
- GetByID: 获取单份试卷
- AddQuestions: 手动选题（仅草稿）
- RandomSelect: 随机组卷（ORDER BY RAND()）
- Publish: 发布（草稿→已发布，校验题目非空+总分一致）
- Unpublish: 撤销（已发布→草稿）
- Copy: 复制（含题目关联）
- Preview: 预览（含题目列表，不返回答案）

### 任务 3.4：试卷 Controller

**文件**: `internal/controller/paper_controller.go`

- List / Create / GetByID / Update / Delete
- AddQuestions / RandomSelect
- Publish / Unpublish / Copy / Preview
