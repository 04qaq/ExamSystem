**1.1.2 初始化 Go Module**
- 执行 `go mod init exam-server`

### 任务 1.3：用户注册与登录

**1.3.1 密码加密工具 (internal/utils/hash.go)**
- `HashPassword(password string) (string, error)` — 使用 bcrypt 加密
- `CheckPassword(hashedPassword, password string) bool` — 验证密码

**1.3.2 通用响应封装 (internal/dto/response.go)**
- 统一 JSON 响应格式：
```json
{
  "code": 0,           // 0 成功，非 0 为错误码
  "message": "success",
  "data": {}           // 可选，具体业务数据
}
```

**1.3.3 用户数据访问层 (internal/repository/user_repo.go)**
- `CreateUser(user *model.User) error` — 创建用户
- `FindByUsername(username string) (*model.User, error)` — 按用户名查询
- `FindByID(id uint64) (*model.User, error)` — 按 ID 查询

**1.3.4 认证业务逻辑 (internal/service/auth_service.go)**
- `Register(req dto.RegisterRequest) (*dto.RegisterResponse, error)`
  - 检查用户名是否已存在
  - 密码强度校验（至少 6 位）
  - bcrypt 加密密码
  - 写入数据库，默认角色为"学生"（非注册接口由管理员创建教师/管理员）
  - 返回用户基本信息
- `Login(req dto.LoginRequest) (*dto.LoginResponse, error)`
  - 按用户名查询用户
  - 验证密码
  - 生成 JWT（包含 user_id、role）
  - 返回 token 与过期时间

**1.3.5 认证控制器 (internal/controller/auth_controller.go)**
- `POST /api/auth/register` — 注册，接收 username、password、real_name
- `POST /api/auth/login` — 登录，接收 username、password，返回 JWT

### 任务 1.4：JWT 与中间件

**1.4.1 JWT 工具 (internal/utils/jwt.go)**
- `GenerateToken(userID uint64, role int, duration time.Duration) (string, error)`
  - 使用 HS256 算法签名
  - Claims 包含：user_id、role、iat、exp
- `ParseToken(tokenString string) (*Claims, error)`
  - 解析并验证 token 有效性
  - 返回自定义 Claims 结构体

**1.4.2 JWT 认证中间件 (internal/middleware/jwt.go)**
- 从请求头 `Authorization: Bearer <token>` 提取 token
- 解析 token，校验有效性
- 将 user_id 和 role 注入 `gin.Context`（使用 `c.Set("userID", ...)` 和 `c.Set("role", ...)`）
- Token 无效时返回 401

**1.4.3 角色鉴权中间件 (internal/middleware/role.go)**
- 工厂函数 `RequireRole(roles ...int) gin.HandlerFunc`
  - 从上下文中取出 role
  - 检查 role 是否在允许列表中
  - 不在列表中返回 403
- 角色常量定义：
  - `RoleAdmin = 1`
  - `RoleTeacher = 2`
  - `RoleStudent = 3`

**1.4.4 CORS 跨域中间件 (internal/middleware/cors.go)**
- 允许前端开发时的跨域请求
- 配置允许的 Origin、Methods、Headers

### 任务 1.5：路由注册与启动

**1.5.1 路由注册 (internal/router/router.go)**
```go
// 公开路由
public := r.Group("/api")
{
    public.POST("/auth/register", authCtrl.Register)
    public.POST("/auth/login", authCtrl.Login)
}

// 需要认证的路由
auth := r.Group("/api")
auth.Use(middleware.JWTAuth())
{
    // 管理员路由
    admin := auth.Group("/admin")
    admin.Use(middleware.RequireRole(RoleAdmin))
    {
        // 后续阶段补充
    }

    // 教师路由
    teacher := auth.Group("/teacher")
    teacher.Use(middleware.RequireRole(RoleTeacher))
    {
        // 后续阶段补充
    }

    // 学生路由
    student := auth.Group("/student")
    student.Use(middleware.RequireRole(RoleStudent))
    {
        // 后续阶段补充
    }
}
```

**1.5.2 应用入口 (cmd/server/main.go)**
- 加载配置
- 初始化日志（zap）
- 初始化数据库
- 初始化答案缓存
- 执行自动迁移
- 执行种子脚本
- 注册路由
- 启动 HTTP 服务（支持优雅关闭）

**1.5.3 优雅关闭**
- 监听系统信号 (SIGINT, SIGTERM)
- 收到信号后：
  - 停止接收新请求
  - 等待进行中的请求完成（设置超时）
  - 关闭数据库连接
  - 刷新缓存中剩余答案至 MySQL

### 任务 1.8：开发登录与注册页面

**1.8.1 登录页面（views/Login.vue）**

- 表单：用户名输入框 + 密码输入框 + 登录按钮
- 角色切换标签：教师 / 学生（若角色确定可省略）
- 登录逻辑：
  1. 调用 `POST /api/auth/login`
  2. 成功后存储 token 到 Pinia（自动持久化）
  3. 根据返回的 `role` 跳转到对应主页：
     - `role=1` → `/admin/dashboard`
     - `role=2` → `/teacher/dashboard`
     - `role=3` → `/student/dashboard`
- 登录失败显示错误提示（用户名不存在、密码错误）
- 底部「没有账号？立即注册」跳转链接

**1.8.2 注册页面（views/Register.vue）**

- 表单：用户名 + 密码 + 确认密码 + 真实姓名
- 前端校验：用户名 ≥ 3 字符、密码 ≥ 6 字符、两次密码一致
- 注册逻辑：
  1. 调用 `POST /api/auth/register`
  2. 成功后提示「注册成功，请登录」并跳转到登录页
  3. 失败显示错误提示（用户名已存在等）
- 底部「已有账号？立即登录」跳转链接

**1.8.3 Wails Go 层配置**

在 `app.go` 中配置应用窗口：
- 窗口标题：`在线考试系统`
- 窗口尺寸：1200×800（可调整）
- 最小尺寸：900×600

## 关键代码示例

### config.yaml 示例
```yaml
server:
  port: 8080
  mode: debug  # debug | release

database:
  host: 127.0.0.1
  port: 3306
  user: root
  password: "your_password"
  dbname: exam_system
  max_open_conns: 100
  max_idle_conns: 10

cache:
  flush_interval: 30   # 答案缓存刷入 MySQL 的间隔（秒）
  max_entries: 100000  # 最大缓存条目数

jwt:
  secret: "your-secret-key-change-in-production"
  access_expire: 24h    # Access Token 过期时间
  refresh_expire: 168h  # Refresh Token 过期时间（7天）
```

### JWT Claims 结构体
```go
type Claims struct {
    UserID uint64 `json:"user_id"`
    Role   int    `json:"role"`
    jwt.RegisteredClaims
}
```
