# 在线考试系统 — 开发文档（与当前实现对齐）

本文档描述仓库目录结构、技术栈、配置、API、数据模型与构建发布流程，便于二次开发与运维。**路径均以仓库根目录 `testsysystem/` 为基准。**

---

## 1. 仓库结构

```
testsysystem/
├── exam-server/              # Go 考试服务（HTTP API）
│   ├── cmd/server/main.go    # 入口：配置、数据库、缓存、发现服务、Gin、优雅退出
│   ├── config/               # config.yaml + Viper 加载
│   ├── internal/
│   │   ├── router/           # 路由注册
│   │   ├── controller/       # HTTP 控制器
│   │   ├── service/          # 业务逻辑
│   │   ├── repository/       # GORM 数据访问
│   │   ├── model/            # 实体与枚举常量
│   │   ├── dto/              # 请求/响应结构
│   │   ├── middleware/       # JWT、CORS、角色鉴权
│   │   ├── discovery/        # UDP+TCP 局域网发现（端口 43210）
│   │   ├── cache/            # 答题内存缓存 + 定时刷库
│   │   └── ...
│   ├── scripts/seed.go       # 默认账号种子（不存在则创建）
│   └── go.mod
├── exam-client/
│   ├── frontend/             # Vue3 + Vite + TypeScript + Pinia + Naive UI
│   │   └── src/
│   │       ├── api/          # Axios 封装与各模块 API
│   │       ├── stores/       # settings / auth
│   │       ├── router/
│   │       ├── views/        # 登录、设置、学生/教师/管理员页面
│   │       └── utils/        # serverDiscovery 等
│   ├── desktop/              # Wails v3 壳 + embed 前端 dist
│   │   ├── main.go           # 资源服务、/discover 中间件
│   │   ├── lanfind/          # 桌面端局域网发现（UDP/TCP/HTTP 扫描）

│   └── build-desktop.ps1     # 一键：npm build → sync → wails3 build
└── 开发/                     # 需求文档、开发文档（本目录）
```

## 2. 技术栈与版本说明

| 部分 | 技术 |
|------|------|
| 考试服务 | Go（`go.mod` 为准）、Gin、GORM、MySQL 驱动、Viper、jwt/v5、golang.org/x/crypto（bcrypt） |
| 前端 | Vue 3、Vite 6、TypeScript、Vue Router、Pinia、Naive UI、Axios |
| 桌面端 | Wails v3（alpha）、WebView2；嵌入 `embed/dist` |
| 配置 | `exam-server/config/config.yaml`（可执行文件同目录下 `config/config.yaml` 优先） |

> 说明：服务端 **未使用 Zap**；日志以标准库 `log` 与 Gin 模式为主。答题持久化除即时 UPSERT 外，另有 **定时 flush** 的内存缓存（见 `internal/cache/answer_cache.go`）。

---

## 3. 配置项（exam-server）

`config/config.yaml` 主要字段：

| 配置块 | 字段 | 含义 |
|--------|------|------|
| `server` | `port` | HTTP 监听端口（如 8080） |
| `server` | `mode` | `debug` / `release`（影响 Gin 与 GORM 日志级别） |
| `database` | host/port/user/password/dbname | MySQL 连接 |
| `database` | max_open_conns / max_idle_conns | 连接池 |
| `cache` | flush_interval | 答案缓存刷库间隔（秒） |
| `cache` | max_entries | 配置结构体已加载；当前 `answer_cache` 实现以定时 flush 为主，未据此截断条目（可后续扩展） |
| `jwt` | secret | **生产必须修改** |
| `jwt` | access_expire / refresh_expire | Token 有效期 |

入口 `cmd/server/main.go` 会优先加载 **可执行文件所在目录** 下的 `config/config.yaml`。

## 4. 数据库与模型

### 4.1 迁移

启动时 `database.AutoMigrate` 自动创建/更新表：`users`、`questions`、`papers`、`paper_questions`、`exam_records`、`answer_details`、`operation_logs`。

### 4.2 角色与用户状态

- `role`：`1` 管理员，`2` 教师，`3` 学生。  
- `status`：`1` 正常，`0` 禁用（登录拒绝）。

### 4.3 题目类型与难度

- 题型：`QuestionTypeSingle/Multiple/Judge/Fill/Short`（1–5）。  
- 难度：`DifficultyEasy/Medium/Hard`（1–3）。

### 4.4 试卷状态

- `PaperStatusDraft` 草稿，`PaperStatusPublished` 已发布，`PaperStatusClosed` 已关闭。

### 4.5 考试记录状态

- `ExamStatusInProgress` 进行中，`ExamStatusSubmitted` 已提交，`ExamStatusGraded` 已批阅。

### 4.6 选项存储

选择题 `options` 字段为 **JSON 字符串数组**；多选题标准答案建议逗号分隔选项标识（判分时会规范化排序后比较）。

## 5. HTTP API 一览

统一 JSON 封装（见 `internal/dto/response.go`）：

- 成功：`{"code":0,"message":"success","data":...}`  
- 失败：`{"code":<非0>,"message":"..."}`  

鉴权：Header `Authorization: Bearer <access_token>`。

### 5.1 公开接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/ping` | 健康/发现探测；`data.service` 为 `exam-server` |
| POST | `/api/auth/register` | 注册（默认学生） |
| POST | `/api/auth/login` | 登录，返回 token 与用户信息 |

### 5.2 管理员 `/api/admin/*`（需管理员角色）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/users?page=&page_size=` | 用户列表 |
| POST | `/users` | 创建用户 |
| PUT | `/users/:id` | 更新用户（姓名、角色、状态、可选密码） |
| GET | `/logs?page=&page_size=&action=` | 操作日志 |

### 5.3 教师 `/api/teacher/*`（需教师角色）

题库：`GET/POST /questions`，`GET/PUT/DELETE /questions/:id`，`POST /questions/import`。  

试卷：`GET/POST /papers`，`GET/PUT/DELETE /papers/:id`，`POST /papers/:id/questions`，`POST /papers/:id/random-select`，`PUT /papers/:id/publish`，`PUT /papers/:id/unpublish`，`POST /papers/:id/copy`，`GET /papers/:id/preview`。  

批阅与统计：`GET /exam/pending`，`GET|POST /exam/records/:id/grade`，`GET /statistics/paper/:id`，`GET /statistics/paper/:id/export`（Excel 下载）。

### 5.4 学生 `/api/student/*`（需学生角色）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/papers` | 可考试卷列表 |
| POST | `/papers/:id/start` | 开考（返回 record_id、题目、剩余秒数） |
| POST | `/exam/:record_id/answer` | 保存单题答案 |
| POST | `/exam/:record_id/submit` | 交卷（body 含切屏计数等） |
| GET | `/exam/records` | 成绩列表 |
| GET | `/exam/records/:id` | 成绩详情 |

完整路由定义见 `exam-server/internal/router/router.go`。

## 6. 局域网发现机制

### 6.1 服务端（exam-server）

- `internal/discovery`：监听 **UDP + TCP 43210**。  
- 收到约定探测报文后回复 JSON（含 HTTP 端口等）或兼容格式 `EXAM|<端口>`。  
- 与 HTTP 服务并行启动；关闭时 `discovery.Stop()`。

### 6.2 桌面客户端

- `desktop/main.go`：在静态资源服务上挂载 **`GET /discover`**，内部调用 `lanfind.Discover`。  
- `lanfind`：依次尝试本机 HTTP ping、UDP 广播、TCP 扫描、网段 HTTP 扫描等；HTTP 客户端对私网/回环 **绕过系统代理**。  
- Windows 构建建议使用 `-ldflags="-s -w -H windowsgui"`，见 `desktop/Taskfile.yml`。

### 6.3 浏览器访问前端时

- `frontend/src/utils/serverDiscovery.ts`：优先同源 `/discover`（桌面）；否则 WebRTC 收集局域网 IPv4 + 网段探测 + 本机端口探测；**不在桌面同源场景下对 `/discover` 返回的地址再做本机 probe**（避免 WebView2 拦截）。

## 7. 前端要点

- **Base URL**：`settings` Pinia store，`effectiveBaseUrl` 为空时使用环境变量 `VITE_API_BASE_URL` 或内置默认本机地址。  
- **HTTP**：`src/api/http.ts` 统一附加 `Authorization`；401 清理会话并跳转登录。  
- **二进制下载**：`getBlob` 用于统计导出等，绕过 Axios JSON 解包。  
- **路由**：`/login`、`/setup`（设置）、`/app/*` 需登录后的壳布局。

本地开发前端：`exam-client/frontend` 执行 `npm install && npm run dev`；若需代理 API，配置 `vite.config.ts`（以当前文件为准）。

## 8. 构建与发布

### 8.1 考试服务

```bash
cd exam-server
go build -buildvcs=false -o exam-server.exe ./cmd/server/
```

将 `config/config.yaml` 与可执行文件一并部署；首次启动确保 MySQL 已建库且账号可连。

### 8.2 桌面客户端

推荐脚本（需本机已安装 Node、Go，且 `wails3` 可用）：

```powershell
cd exam-client
.\build-desktop.ps1
```

产物：`exam-client/desktop/bin/ExamSystem.exe`。

手工等价步骤：

1. `cd exam-client/frontend && npm run build`  
2. `exam-client/desktop/scripts/sync-frontend.ps1`（拷贝 `frontend/dist` → `desktop/embed/dist`）  
3. `cd exam-client/desktop`，Windows 下：

```powershell
$env:GOOS="windows"; $env:CGO_ENABLED="0"; $env:GOARCH="amd64"
go build -buildvcs=false -ldflags="-s -w -H windowsgui" -o bin/ExamSystem.exe .
```

`.gitignore` 通常忽略 `embed/dist`、`bin/*.exe`、根目录 `*.exe`，**仓库内不包含打包后的二进制**，需在 CI 或本地构建生成。

## 9. 默认种子账号

`scripts/SeedAdmin()` 在用户不存在时创建（控制台打印明文密码一次）：

| 用户名 | 角色 | 用途 |
|--------|------|------|
| admin | 管理员 | 运维/用户管理 |
| teacher | 教师 | 题库与试卷 |
| student | 学生 | 答题验收 |

**生产环境请修改默认密码或禁用种子逻辑。**

## 10. 调试建议

- API：Postman / curl，先 `POST /api/auth/login` 取 Token。  
- 数据库：直接查询 `exam_records`、`answer_details` 核对交卷与批阅状态。  
- 发现：`GET http://<host>:<port>/api/ping` 应返回 `code=0` 且 `data.service=exam-server`。  
- 桌面连接问题：检查防火墙、代理、`BlockInsecurePrivateNetworkRequests` 相关浏览器参数（桌面 `main.go` 已配置 AdditionalBrowserArgs）。
