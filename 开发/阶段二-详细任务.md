# 阶段二：题库管理模块 - 详细任务

## 目标
实现完整的题库管理功能，教师可以创建、编辑、删除、查询和批量导入题目。

## 服务端任务

### 1. 创建题目 DTO (dto/question.go)
- `CreateQuestionRequest` — 创建题目请求（题型、题干、选项、答案、分值、难度、标签）
- `UpdateQuestionRequest` — 更新题目请求
- `QuestionQuery` — 分页查询参数（type/difficulty/tag/keyword/page/page_size）
- `QuestionResponse` — 题目响应结构
- `QuestionListResponse` — 分页列表响应（total + items）
- `ImportQuestionItem` — 批量导入单项
- `ImportRequest` — 批量导入请求
- `ImportResponse` — 导入结果（total/success/fail）

### 2. 创建题目 Repository (repository/question_repo.go)
- `Create(question)` — 新建题目
- `Update(question)` — 更新题目
- `Delete(id)` — 逻辑删除（is_deleted = 1）
- `FindByID(id)` — 查询单题（排除已删除）
- `List(type, difficulty, tag, keyword, page, pageSize)` — 分页+筛选查询
- `BatchCreate(questions)` — 批量创建（每批100条）

### 3. 创建题目 Service (service/question_service.go)
- `Create(req, creatorID)` — 创建题目业务逻辑，校验选择题必须提供选项
- `Update(id, req, teacherID)` — 更新题目，校验归属权（只能编辑自己的题目）
- `Delete(id, teacherID)` — 删除题目，校验归属权
- `GetByID(id)` — 获取单题详情
- `List(query)` — 分页查询
- `Import(req, creatorID)` — 批量导入

### 4. 创建题目 Controller (controller/question_controller.go)
- `POST /api/teacher/questions` — 创建题目
- `PUT /api/teacher/questions/:id` — 更新题目
- `DELETE /api/teacher/questions/:id` — 删除题目
- `GET /api/teacher/questions/:id` — 获取题目详情
- `GET /api/teacher/questions` — 分页查询（支持 type/difficulty/tag/keyword 筛选）
- `POST /api/teacher/questions/import` — 批量导入

### 5. 更新路由 (router/router.go)
- 在 teacher 分组下注册题目路由

## 客户端任务

### 1. 创建 API 模块 (api/question.ts)
- `getQuestions(params)` — 获取题目列表（分页+筛选）
- `getQuestion(id)` — 获取题目详情
- `createQuestion(data)` — 创建题目
- `updateQuestion(id, data)` — 更新题目
- `deleteQuestion(id)` — 删除题目
- `importQuestions(data)` — 批量导入

### 2. 创建题目 Store (stores/question.ts)
- 题目列表状态管理
- 分页状态
- 筛选条件

### 3. 创建教师端布局 (layouts/TeacherLayout.vue)
- 左侧导航栏（控制台、题目管理）
- 顶部用户信息
- 右侧内容区

### 4. 创建教师控制台页面 (views/teacher/TeacherDashboard.vue)
- 欢迎信息
- 题目数量概览

### 5. 创建题目列表页 (views/teacher/QuestionList.vue)
- 表格展示题目（ID、题型、题干、难度、分值、标签、创建时间、操作）
- 筛选栏：题型下拉、难度下拉、关键词搜索
- 分页组件
- 新建/批量导入按钮
- 删除确认弹窗

### 6. 创建题目表单页 (views/teacher/QuestionForm.vue)
- 支持新建和编辑两种模式（根据路由参数判断）
- 题型选择（单选/多选/判断/填空/简答）
- 题干输入
- 选项输入（仅选择题显示）
- 答案输入
- 分值输入
- 难度选择
- 标签输入

### 7. 创建批量导入页 (views/teacher/QuestionImport.vue)
- JSON格式批量导入
- 预览导入结果（成功/失败数量）

### 8. 更新路由 (router/index.ts)
- 添加 /teacher 嵌套路由（TeacherLayout + 子页面）
- 添加路由守卫（requiresAuth + role 检查）
