# 阶段四：学生考试模块 - 详细任务

服务端实现考试全流程 API（开始考试、答案实时保存、提交判分）；客户端实现学生答题界面（倒计时、题目导航、防作弊）。

### 任务 4.3：考试 Service

**文件**: `internal/service/exam_service.go`

**1. GetAvailablePapers** — 可考试卷列表
- 查询 status=1（已发布）且当前时间在 start_time~end_time 之间的试卷
- 每份试卷附带学生是否已提交（防止重复考试）

**2. StartExam** — 开始考试
- 校验试卷已发布且在有效时间内
- 检查该学生是否有进行中的考试记录（如有则返回进行中的记录，继续考试）
- 创建 ExamRecord（status=1 进行中，start_time=now）
- 从 PaperQuestions 获取题目，打乱 sort_order 顺序（防作弊）
- 选择题选项也随机打乱（返回前端乱序后的选项）
- 返回 record_id + 题目列表 + 剩余秒数

**3. SaveAnswer** — 保存答案
- 校验 record 属于该学生且状态为进行中
- 写入 `cache.GlobalCache.Set(recordID, questionID, answer)`
- 同时写入 answer_details（直接持久化 + 缓存双写保证不丢）
- 返回成功

**4. SubmitExam** — 提交试卷
- 校验 record 属于该学生且状态为进行中
- 从缓存刷入所有答案到 answer_details
- 遍历 answer_details，对客观题（单选/多选/判断）逐题判分：
  - 单选用户答案与标准答案比对
  - 多选题答案按分割排序后比对
  - 判断题直接比对
- 计算总分，更新 ExamRecord（status=2 已提交，submit_time=now，total_score=计算结果）
- 清除缓存中该 record 的数据
- 计算切屏次数保存到快照（如有传参）

**5. GetRecords** — 考试记录列表
- 按用户 ID 分页查询 exam_records

**6. GetRecordDetail** — 成绩详情
- 查询 exam_record + 关联的 answer_details
- 返回每题得分、正确答案、学生答案、对错状态

### 任务 4.11：考试答题页

**文件**: `frontend/src/views/student/ExamTaking.vue`

核心界面：
- **顶部**：试卷标题 + 倒计时（时:分:秒，红色闪烁警告）
- **左侧**：题号导航面板（已答/未答/当前高亮标记）
- **中部**：当前题目内容 + 选项/输入区域
  - 单选 → radio 按钮
  - 多选 → checkbox 按钮
  - 判断 → 对/错 radio
  - 填空 → input
  - 简答 → textarea
- **底部**：上一题 / 下一题 按钮 + 提交按钮

功能：
- 每题切换时自动保存答案（调用 saveAnswer API）
- 倒计时归零自动提交（拦截请求到后端）
- 题号面板显示答题进度（绿色=已答，灰色=未答，蓝色=当前）
- 提前交卷需要二次确认弹窗

**防作弊**：
- 监听 `visibilitychange` 事件，切出 tab 记录次数并在提交时上报
- 禁用右键菜单 `contextmenu`
- 禁用复制 `copy`
- 切出超过 3 次弹出警告
