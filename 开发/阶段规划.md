# 在线考试系统 - 开发阶段规划

## 总体概述
将整个项目拆分为 7 个开发阶段，每个阶段同时推进服务端 API 和桌面客户端开发，前后端增量构建、并行交付。

## 系统架构

```
Wails 桌面客户端 (Vue3 + Go WebView)
    │  HTTP/JSON (Axios)
    ▼
Go API 服务端 (Gin, 纯后端)
    │
    ▼
MySQL 8.0
```

### 项目结构

```
exam-system/
├── server/     # Go API 服务端
└── client/     # Wails + Vue3 桌面客户端
```

---

## 阶段一：项目基础与用户认证
**目标**：搭建服务端项目骨架、数据库与认证 API；搭建 Wails 客户端项目骨架、登录注册页面。

**服务端产出**：
- 项目目录结构与 6 张表 Model
- 数据库 AutoMigrate + 种子数据
- 注册/登录 API（JWT）
- 认证 + 角色鉴权 + CORS 中间件
- 答案缓存（sync.Map）

**客户端产出**：
- Wails v3 + Vue3 + TypeScript 项目脚手架
- Vue Router + Pinia 状态管理 + Axios 封装
- 登录页面 + 注册页面
- 用户信息存储与 Token 管理

---

## 阶段二：题库管理模块
**目标**：服务端题库 CRUD + 批量导入；客户端教师题目管理界面。

**服务端产出**：
- 五种题型 CRUD API
- 分页查询 + 按题型/难度/标签筛选
- Excel/CSV 批量导入接口

**客户端产出**：
- 教师端题目列表页（表格 + 分页 + 筛选）
- 题目创建/编辑表单页
- 批量导入题目页面

---

## 阶段三：试卷管理模块
**目标**：服务端试卷 CRUD + 组卷；客户端教师试卷管理界面。

**服务端产出**：
- 试卷 CRUD API
- 手动选题 + 随机组卷 API
- 发布/撤销/复制接口
- 试卷预览接口

**客户端产出**：
- 教师端试卷列表页
- 创建试卷向导（基本信息 + 手动选题 + 随机组卷规则）
- 试卷预览页面

---

## 阶段四：学生考试模块
**目标**：服务端考试流程 + 自动判分；客户端学生答题界面。

**服务端产出**：
- 开始考试 / 答案实时保存 API
- 提交试卷 + 自动判分（客观题）
- 倒计时超时强制提交
- 防作弊（随机题目/选项顺序、切屏记录）

**客户端产出**：
- 学生端可考试卷列表页
- 答题界面（倒计时、题目导航、标记未答、翻页）
- 答案实时保存（每选一题即发请求）
- 提前交卷二次确认弹窗
- 防作弊（切屏检测、禁用右键）

---

## 阶段五：成绩与批阅模块
**目标**：服务端批阅 + 统计；客户端批阅页面 + 成绩查看。

**服务端产出**：
- 学生成绩列表 + 答题详情
- 教师批阅主观题 API
- 成绩统计（平均分、分布、正确率）
- 成绩导出 Excel

**客户端产出**：
- 学生端成绩列表 + 答题详情页
- 教师端待批阅列表 + 批阅打分页
- 成绩统计图表页
- 成绩导出功能

---

## 阶段六：管理功能
**目标**：管理员用户管理、系统日志。

**服务端产出**：
- 用户管理 API（列表、角色修改、状态管理）
- 班级/学生批量导入
- 关键操作日志记录

**客户端产出**：
- 管理员端用户管理页
- 班级管理页
- 系统日志查看页

---

## 阶段七：打包与部署
**目标**：服务端容器化部署、客户端打包分发。

**产出**：
- 服务端 Docker 容器化 + Docker Compose（MySQL + Server）
- Nginx 反向代理配置
- 客户端 Wails 打包为 Windows .exe
- CI/CD 基础配置
- 压力测试脚本

---

## 阶段依赖关系

```
阶段一（基础+认证）
    │
    ├──→ 阶段二（题库管理）
    │        │
    │        └──→ 阶段三（试卷管理）
    │                 │
    │                 ├──→ 阶段四（学生考试）
    │                 │        │
    │                 │        └──→ 阶段五（成绩批阅）
    │                 │
    │                 └──→ 阶段六（管理功能）
    │
    └──→ 阶段七（打包部署，可提前准备）
```

每个阶段内部，服务端 API 优先完成 → 客户端对接开发 → 联调验证。
